# struck-shell-chaos-files

Public files of the struck-shell-chaos project ("When is a struck shell chaotic"), served by GitHub Pages at https://magland.github.io/struck-shell-chaos-files/: listening pages and sounds for the project's reports, and possibly other files later.

Each report has a folder, `NN-name/`, with its pages at the top and its files in subfolders (`audio/`, ...). Files are content addressed (`NAME-SHA12.EXT`), so a link never changes meaning; a regenerated file gets a new name. Everything here is written by the reports' scripts in the (separate, private) project repository; do not edit it by hand.

Sounds by other authors are not re-hosted here; the pages play them from their original locations.
